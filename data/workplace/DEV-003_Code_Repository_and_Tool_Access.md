# DEV-003: Code Repository, Issue Tracker and Wiki Access (synthetic analogue)

Owner: Developer Tools Team

## Access Model
- Access to code repositories is granted per team group, approved by the repository owner.
- New joiners get their team's groups automatically from the HR role; everything else is requested.
- External contractors get access only to repositories marked for vendor collaboration.

## Common Requests
- **Repository access:** raise a "Repository Access" request naming the repository; approval by the owner, applied within 4 hours.
- **SSH key or token problems:** personal access tokens expire every 90 days; create a new one with the minimum scopes needed.
- **Issue tracker / wiki permissions:** project admins can add members directly; the service desk handles only missing licences.

## Using Public AI Tools With Code or Documents
Source code, supplier contracts and other Confidential material must not be pasted into public AI chatbots or code assistants. Use only the approved internal GenAI platform (DEV-001).
