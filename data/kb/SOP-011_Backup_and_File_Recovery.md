# SOP-011: Backup and File Recovery

Owner: Collaboration Services

## What Is Backed Up
- Desktop, Documents and Pictures folders are redirected to OneDrive (Known Folder Move) and are backed up automatically.
- Files saved elsewhere on the laptop (for example `C:\Data`) are **not** backed up.

## Restoring a Deleted File
1. Check the OneDrive recycle bin: deleted files are kept for 93 days.
2. For an earlier version of a file, use Version History in OneDrive or SharePoint (the last 500 versions are kept).
3. To roll back many files at once (for example after ransomware), use "Restore your OneDrive" to a point in the last 30 days.

## Shared Drive Restore
Files on network shares are backed up nightly and kept for 35 days. Raise a restore request with the full path and the approximate time of deletion; restores are done by the Storage team within 1 business day.

## Ransomware
If many files suddenly have a new extension or cannot be opened, disconnect the laptop from the network immediately and raise a P1 to the Security Operations Centre. Do not try to restore files before SOC approves.
