# SOP-007: Software Installation and Licence Requests

Owner: End User Computing (EUC) and Software Asset Management (SAM)

## Standard Software
Approved software (browsers, 7-Zip, Notepad++, Python, VS Code, Git, Postman, Power BI Desktop) is self-service:
- Windows: install from **Software Center**.
- macOS: install from **Self Service**.
Users do not have local administrator rights; agents must not grant them to install software.

## Non-Standard or Licensed Software
1. The user raises a Software Request in the service portal with the business justification and their manager as approver.
2. SAM checks for a free licence in the pool. Licences unused for 90 days are reclaimed automatically.
3. Security reviews any software that is not on the approved list. Typical review time is 5 business days.
4. Once approved, EUC packages it for Software Center / Self Service. Priority for software requests is P4.

## Common Issues
- "Installation failed" in Software Center: restart the laptop and retry; check free disk space (at least 10 GB).
- Licence error in Adobe or Microsoft 365 apps: sign out and sign back in with the corporate account; the licence is tied to the user, not the device.
