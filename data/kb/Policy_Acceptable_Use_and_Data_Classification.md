# Policy: Acceptable Use and Data Classification

Owner: Information Security

## Data Classification
| Label | Examples | Rules |
|---|---|---|
| Public | Press releases, website content | No restrictions |
| Internal | Org charts, internal announcements | Share only with employees |
| Confidential | Customer data, contracts, source code | Encrypted storage; no external sharing without approval |
| Strictly Confidential | Unreleased financials, M&A, credentials | Named individuals only; never in email or chat |

## Generative AI Tools
Employees may use only company-approved AI tools. Confidential or Strictly Confidential data must never be pasted into public AI chatbots.

## USB Storage
USB mass storage is blocked on company laptops. Exceptions require Information Security approval and an encrypted company USB drive.

## Reporting
Report lost or stolen devices to the service desk within 1 hour; this is handled as a P1 security incident and the device is remote-wiped.
