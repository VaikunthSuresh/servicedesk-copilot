# SOP-004: Laptop Hardware, Network Basics and Printer Issues

Owner: End User Computing (EUC)

## Laptop Running Slow
1. Check free disk space; below 10% free, run Disk Cleanup and clear the Downloads folder with the user's consent.
2. Open Task Manager and check for processes using more than 80% CPU or memory for several minutes.
3. Make sure pending Windows updates are installed and the laptop has been restarted in the last 7 days.
4. If the laptop is older than 4 years, raise a hardware refresh request instead of continuing to troubleshoot.

## Laptop Will Not Boot / Blue Screen
1. Note the stop code shown on the blue screen.
2. Hold the power button for 15 seconds, disconnect docks, and try again.
3. If BitLocker recovery is requested, retrieve the recovery key from Entra ID only after identity verification.
4. Physical damage (liquid spill, broken screen): log as hardware incident, issue a loaner laptop, and send the device to the EUC hardware desk. Typical repair SLA is 3 business days.

## Network Basics
- Wired: check the cable and the link light; try another port.
- Wi-Fi: forget and rejoin the corporate SSID; the certificate must be valid.

## Printer Issues
1. Confirm the user is printing to the secure follow-me print queue, not a direct printer IP.
2. Clear stuck jobs: restart the "Print Spooler" service.
3. Paper jams and toner are handled by Facilities, not IT. Re-route those tickets to Facilities.
